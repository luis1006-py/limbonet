LIMBONET es una herramienta para la gestión de redes en sistemas GNU/Linux

Diseñado para administradores, permite controlar cada aspecto de tu infraestructura de red desde un único panel intuitivo

Funciones principales:

Configuración de DNS y resolución de nombres

Gestión de DHCP para asignación automática de direcciones IP

Administración de direcciones IP y rutas de manera centralizada

Configuración de VLANs
